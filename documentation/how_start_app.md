## Что сделать перед запуском в эмуляторе

### Шаг 0 - хост бэкенда

В `HttpClientFactory` прописать `BASE_URL` хоста с бэкендом

### Шаг 1 — Создай эмулятор (если ещё нет)

В правой панели Android Studio найди иконку `Device Manager` (телефон с маленьким Android)
Нажми `Create Virtual Device`
Выбери `Pixel 6` → `Next`
Выбери системный образ `API 34 (VanillaIceCream)` → `Next` → `Finish`

### Шаг 2 — Запусти эмулятор

В `Device Manager` нажми кнопку ▶️ рядом с созданным устройством. Подожди пока загрузится (1-2 минуты).

### Шаг 3 — Запусти приложение

Вверху Android Studio:

В выпадающем списке убедись что выбрано app
Рядом выбери свой эмулятор
Нажми зелёный ▶️ Run

### Шаг 4 — Проверь логи
Внизу откройся вкладка Logcat. В строке фильтра напиши:
`package:spending.tracker.android`
Там будут видны все запросы к бэку и ошибки.

Для мониторинга соединений, фильтруем логи по: `KtorHttpClient`
